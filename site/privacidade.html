Política de privacidade

finan_rich · atualizada em 23 de outubro de 2026

O finan_rich é um app de finanças pessoais gratuito e de código aberto (github.com/alexandreserra1/finan_rich). Ele foi feito para que os seus dados fiquem com você.

Onde ficam os seus dados

  • No seu aparelho. Lançamentos, contas, dívidas, metas e notas ficam no navegador, no celular ou no computador em que você usa o finan_rich. Não existe servidor do finan_rich que guarde esses dados.
  • No seu Google Drive, se você escolher "Entrar com Google". Os dados vão para uma pasta de dados do app no seu Drive (escondida, que só o finan_rich lê), para aparecerem nos seus outros aparelhos. O finan_rich não vê nem guarda esse arquivo em lugar nenhum além do seu Drive.

Login com Google: o que o app acessa

  • Seu e-mail, só para mostrar qual conta está ligada.
  • A pasta de dados do app no seu Drive (permissão drive.appdata). O app não enxerga nenhum outro arquivo do seu Drive.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. Os dados não são vendidos, não são usados para anúncios e não são repassados a ninguém.

Para entrar, o código de acesso que o Google devolve passa pelo intermediário do finan_rich (na Vercel), que só o troca com o Google e não guarda nada. Você pode sair a qualquer momento em Ajustes, ou retirar o acesso em myaccount.google.com/permissions.

Consultor com IA

Quando você pergunta ao consultor na nuvem, o app troca nomes de lojas, pessoas, dívidas e metas por apelidos antes de enviar ("Loja AB", "Dívida 1") e deixa as notas de fora. Na opção "finan_rich grátis", a pergunta passa por um intermediário na Vercel até o Groq, que não usa os dados para treinar modelos. O intermediário não guarda as perguntas. Se você usar a sua própria chave de IA, a pergunta vai direto para o provedor que você escolheu.

Open Finance e notificações do banco

São opcionais. No Open Finance (Meu Pluggy), os lançamentos vão do banco para o seu aparelho com a sua própria conta Pluggy, sem passar por servidor do finan_rich. No Android, as notificações dos apps de banco que você autorizar viram lançamentos para conferir, e ficam só no celular.

Apagar seus dados

Em Ajustes → "Apagar dados" o app apaga tudo do aparelho. O arquivo no seu Drive pode ser apagado em drive.google.com → Configurações → Gerenciar apps → finan_rich → Excluir dados ocultos do app.
